# 站点公告

公告显示在首页和“所有公告”页（`/announcements`），所有人都能看，包括没有登录的人。每条公告都写明**发布者**和发布时间。

## 发布

管理员和系统管理员打开“所有公告”页，右上角有“发布公告”：

- **标题**。
- **置顶**：不置顶、置顶、置顶并排在前面、置顶并排在最前。置顶的公告排在其他公告上面，同一级里新的在前。
- **正文**：Markdown，公式写 `$…$`。
- **图片、视频和其他文件**：可以一次选几个。发布后，图片直接显示在正文里，视频和音频可以在页面上播放（可拖动进度），
  其他文件是下载链接；它们先加在正文末尾。想放到别的位置：再点“编辑”，把正文里对应的那一行移过去——
  编辑页下方列出了每个文件“写在正文里的样子”，点一下即可复制。

发布之后在公告页右上角“编辑”“删除”。别的管理员修改公告时，发布者仍然是最初发布的人；修改和删除都记在审计日志里。
删除公告会连同它带的文件一起删除。

## 文件的限制

和题目、比赛的附件共用同一组上限（见 [deployment.md](deployment.md) 的 `attachments`）：单个文件默认不超过 100 MB，
一条公告最多 50 个文件。要放更大的视频，调大 `attachments.max-file-mb`。

浏览器里直接显示或播放的只有这些类型：图片 `png`、`jpg`、`gif`、`webp`，视频 `mp4`、`webm`、`ogv`、`mov`，
音频 `mp3`、`ogg`、`wav`、`m4a`，以及 `pdf`。其他文件（包括 `svg` 和 `html`）一律作为下载，不会被当成本站的页面打开。
视频建议用 H.264 编码的 `mp4`，各种浏览器都能播放。

## 和博客的关系

公告在数据库里是一篇标记为“重要”的博客文章，所以以前在“系统管理 → 博客”里登记的公告照常显示在这里，
旧地址 `/blogs/<编号>` 也仍然有效。博客功能关闭时公告不受影响。
